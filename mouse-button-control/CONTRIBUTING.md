# Contributing to Mouse Button Control

Thanks for your interest in contributing! Here's how you can help.

## Reporting Bugs

1. Check if the bug hasn't been reported yet
2. Create a new issue with:
   - Clear title
   - Description of the problem
   - Steps to reproduce
   - Expected vs actual behavior
   - Your environment (OS, Python version, etc.)

## Feature Requests

1. Check if the feature hasn't been requested yet
2. Create a new issue with:
   - Clear title
   - Detailed description
   - Use cases
   - Possible implementation

## Pull Requests

1. Fork the repository
2. Create a branch: `git checkout -b feature/amazing-feature`
3. Make your changes
4. Test your changes: `pytest`
5. Format code: `black mouse_button_control/`
6. Lint code: `flake8 mouse_button_control/`
7. Commit: `git commit -m 'feat: add amazing feature'`
8. Push: `git push origin feature/amazing-feature`
9. Open a Pull Request

## Code Style

- PEP 8 compliant
- Use type hints
- Write docstrings
- Black formatting
- 88 character line length

## Commit Messages

- `feat:` for new features
- `fix:` for bug fixes
- `docs:` for documentation
- `test:` for tests
- `refactor:` for refactoring
- `chore:` for maintenance

## Questions?

Feel free to open an issue for questions!
